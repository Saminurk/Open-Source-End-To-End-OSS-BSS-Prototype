# OSS/BSS Prototype (mini)


Run:
1. create venv with below command
python -m venv venv 

2. activate venv

3. install required packages

4. run the docker

5. run the below command to start the Service
docker-compose build
docker-compose up -d

6. check containers if they are running
docker ps

7. open the below link 
http://localhost:3000
